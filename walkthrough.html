1.0 System Architecture & Core Stack
Full-Stack Cloud Run

The application is a full-stack real-time proactive banking platform containerized as a multi-stage Docker image and hosted on Google Cloud Run with native Identity-Aware Proxy (IAP).

1. Frontend Tier (React 19 + Vite)

Responsive client with Swiss typographic hierarchy, dark/light theme switching, and live audio PCM capture & playback at 16kHz / 24kHz.

2. Backend Tier (Python FastAPI)

Asynchronous REST API, cryptographic IAP JWT verification middleware (iap_jwt_middleware.py), and strict cache-control SPA static asset serving.

3. AI Platform (Gemini Enterprise Agent Platform)

Native ADC connection to gemini-3.7-flash for structured financial reasoning and gemini-3.5-flash-live-preview for low-latency bidirectional voice & tool calling.

Security & Zero Hardcoding Policy: No GCP Project IDs, Regions, or service account keys are hardcoded. Local development listens on 127.0.0.1:8090 via ADC, while Cloud Run uses attached Service Account credentials (roles/aiplatform.user).

1.0 Strategic Value & Personnalité Client Experience
Executive Summary

The Banco Itaú AI Concierge transforms traditional reactive banking into proactive, high-touch wealth advisory for affluent Itaú Personnalité clients.

Autonomous Overdraft Prevention

Rather than charging penal overdraft rates (LIS), the system identifies upcoming liquidity shortfalls and schedules zero-friction CDB DI sweeps so funds earn 100% CDI until the exact millisecond of debit clearance.

Open Finance Rate Arbitrage

Leveraging Brazil's Open Finance ecosystem, the concierge detects expensive debt held at competitor institutions (11.20%/month) and refinances it into pre-approved Itaú Sob Medida credit (1.69%/month), saving clients over R$ 14.000 in interest.
